# M44.1 – Builder skici na serveru

**Cíl:** Skica jako featura v C++ regeneraci: builder skici nad modelem z [[M44-skica-na-serveru|M44]] a jádrem z [[M42-jadro-occt-nativne|M42]]; server při každém `setParams` skici skicu znovu vyřeší a jeho výsledek platí.

> Hrubý plán série nativního jádra (2026-10-17). Před zahájením upřesnit úkoly, kontrakt a Implementační plán.
>
> Vzniklo rozdělením původního M44 (Pavel 2026-10-17): tahle část potřebuje regeneraci (M43), model skici a řešič ne.

**Specifikace:** [[12-skicar]], [[14-protokol]], [[0030-nativni-jadro-pres-grpc|ADR 0030]]

**Navazuje na:** [[M43-regenerace-v-cpp]], [[M44-skica-na-serveru]]

## Úkoly

- [ ] C++ plugin skici: schéma (deklarativní část, `validate` přes `Sketch::parse` z M44, `defaults`) v registru z [[M40-dokument-a-operace-v-cpp|M40]] (`server/src/features/sketch/`, doplnit do `registerBuiltInSchemas`); sdílené případy `validate-sketch-*` (8), které M40 přeskakuje ([[Rozhodnutí nativního jádra|N22]]).
- [ ] Builder skici: oblasti a plochy přes jádro (`profileRegions`, `makeFace`), artefakt skici pro `SketchView` ([[14-protokol#Read model a sítě]]).
- [ ] Chování podle [[Q103 Skica, kterou server nevyřeší|Q103]]: opětovné řešení v handleru `feature.setParams` skici; nevyřešená skica → `SKETCH_NOT_SOLVED` a dokument beze změny, vyřešená se uloží v řešení serveru a klient ho převezme bez tolerance (klíč `sketch.notSolved` i v `messages` skicáře).
- [ ] Sdílené případy regenerace se skicami z M38 (`sketch-*`, vysunutí a rotace ze skici) zelené v C++.

## Akceptační kritéria

- Skici všech druhů entit z M25–M37 dají v C++ stejné oblasti a souřadnice jako v TS (v toleranci) – sdílené případy `regen` se skicami zelené.
- `setParams` nevyřešitelné skici skončí `SKETCH_NOT_SOLVED` a dokument ani log se nezmění.

## Co se naučíš

Dva modely téže domény ve dvou jazycích a jak je udržet ve shodě; server jako autorita nad daty, která klient počítá lokálně.
